========================================================================
                      XAppGroup - Version 1.2.0
      Smart Application Grouping & Flyout Taskbar Launcher
========================================================================

QUICK START:
1. Extract all files from this folder into any directory of your choice 
   (e.g., C:\Tools\XAppGroup or your Desktop).
2. Double-click "XAppGroup.exe" to launch.
3. No installation or administrative privileges required!

SYSTEM REQUIREMENTS:
- Windows 10 (Build 19041+) or Windows 11 (64-bit)
- Microsoft .NET 10 Desktop Runtime
  (If not already installed, download it from https://dotnet.microsoft.com)

FEATURES:
- Group multiple apps into neat taskbar flyouts
- Pin groups directly to Windows Taskbar or Desktop
- Custom Global Hotkeys (e.g., Ctrl + Alt + G)
- Taskbar Jump List shortcuts (Open All / Edit Group)
- Fluent Dark Acrylic & Light Glass themes with Amber Gold accents
- 100% portable with clean unpin & shortcut cleanup on group deletion

CONFIGURATION:
- Customize your GitHub repo & support link in "appconfig.json".
